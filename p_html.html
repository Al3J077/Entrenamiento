Comencemos con los ELEMENTOS SEMÁNTICOS

Los elementos semanticos los definiría como la estructura del HTML, para saber como DEBERÍA ordenarse nuestra pagina desde el codigo, de forma que se nos "simplifique" saber donde va la cabecera (parte de arriba de la pagina), el cuerpo (lo que va debajo de la cabecera, es decir, la mitad de la pagina), el pie (la parte de MAS abajo de la pagina) e incluso, lo no visible de la pagina (que es de los elementos que van primero en codigo HTML).

Los elementos semanticos de estructura principal son:

  • Head:

    Aquí va lo NO visible de la pagina, como documentos, licencias, etc...

  • Body:

    Dentro de este elemento va TODO el contenido visible de la pagina, por lo que dentro de esta etiqueta tambien deben ir el Header y el Footer

  • Header:

    Aquí va la cabecera de la pagina, es decir, la parte de arriba de la pagina, que generalmente contiene el titulo y otros elementos relacionados con la estructura de la pagina

  • Footer:

    En este apartado va el pie de la pagina, es decir, la parte de abajo de la pagina, que generalmente contiene información de contacto, derechos de autor, etc...

Ahora, veamos los elementos de contenido, (tambien conocidos como ETIQUETAS)

Las etiquetas son los elementos que nos permiten crear contenido dentro de nuestra pagina web, como texto, imágenes, enlaces, etc...

Las etiquetas más comunes son:

Etiqueta Descripción
<h1> a <h6> Encabezados de diferentes niveles, siendo h1 el de tamaño mas grande, h2 un poco mas pequeño, así sucesivamente, hasta el h6 que es el de menor tamaño.
<p> Te permite escribir un parrafo de texto
<a> Enlace a otra página o recurso
<img> Imagen.
<!--> Comentario
<hr> Salto de linea CON trazo visible
<br> Salto de linea SIN trazo
<section> Agrupacion de contenido que pertenece al mismo tema o proposito dentro de una pagina
<article> Una pieza de contenido que tiene sentido por SI misma
<div> Sirve para dividir el contenido, u ordenarlo como contenedor, para poder personalizarlo con CSS, JS
<nav> Es la zona donde pueden ir menús de navegación (como en el encabezado, que pueden ir pestañas, o diferentes enlaces)
<id> Para darle un identificador UNICO a un elemento y personalizarlo con CSS y JS (Su identificador es # + id)
<class> Sirve para darle un identificador a uno o VARIOS elementos (Su identificador es . + nombre de clase)

¿Como hacemos FORMULARIOS en HTML? y sus diferentes tipos...

En HTML nosotros podemos hacer diferentes formularios con el fin de poder recolectar información e interactuar con datos ingresados por el usuario, ya sea para poder contactarlo, o para poder hacer algún tipo de enuesta, entre otros...

Las etiquetas para poder crear FORMULARIOS son:

  • Form:

    Es el contenedor principal, en donde se pondrán todas las etiquetas del formulario, el que agrupa todos los datos para poder hacer el formulario. Es el que define el destino DONDE llegará el formulario, y tambien COMO lo hará

  • Label:

    Es el titulo o texto descriptivo que aparecerá por fuera de cada barra o indicador del formulario, además de permitirnos conectar etiquetas, y mejorar la usabilidad y accesibilidad

  • Input:

    El input es el que nos crea, ya sea la barra o el indicador del formulario, donde el usuario ingresa sus datos o marca una casilla en caso tal.

  • Button:

    Crea un boton. A este tambien se le puede asignar un tipo de botón, como submit.

Los diferentes tipos de inputs son:
Input Descripción
"submit" Botón de confirmación
"text" Se escribe lo que se esté pidiendo
"email" Valor de tipo correo electronico
"password" Valor tipo contraseña (se oculta)
"radio" Sirve SOLO para marcar una opción
"checkbox" Similar a radio, pero es de multiple opción
"file" Para pedirle al usuario que suba un archivo local

¿Como hacemos listas en HTML?

En HTML nosotros podemos hacer diferentes tipos de listas, con el fin de poder organizar información y presentarla de una manera más clara y ordenada, ya sea para poder enumerar elementos, o para poder hacer una lista de tareas, entre otros...

Las diferentes tipos de listas son:

Listas NO ordenadas:

Sirven para agrupar elementos donde el orden no importa, como para una lista de compras, caracteristicas de un producto, etc... (UL, li)

EJEMPLO:
  • Elemento 1
  • Elemento 2
  • Elemento 3
Listas ordenadas:

Sirven para agrupar elementos donde el orden es importante, como para una lista de pasos a seguir, una lista de tareas pendientes, etc... (OL, li)

EJEMPLO:
  1. Elemento 1
  2. Elemento 2
  3. Elemento 3
